# Portafolio — Brayan Sandoval

Portafolio profesional (Next.js App Router + TypeScript + Tailwind CSS) con 4 demos interactivas ficticias:
SabanaGrill, Caribe Stay, FerreControl y SmartBooking.

## Configuración
Edita `src/config/site.ts` para cambiar el número de WhatsApp, correo y ubicación.

## Desarrollo
```bash
npm install
npm run dev
npm run build
```

## Despliegue en Vercel
Importa el repositorio en https://vercel.com/new (preset Next.js, sin variables de entorno) y pulsa Deploy.
